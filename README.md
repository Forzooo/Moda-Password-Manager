# Moda - Password Manager
## Informazioni generali
* Linguaggi utilizzati: Java
* Licenza: GPL-3.0
* Sviluppatori: Forzo, Bronte

## Guida all'uso del software
### Installazione
Per installare il password manager è necessario andare nella sezione releases della repository e scaricare il file, del
tuo sistema operativo, dell'ultima versione rilasciata. \
Dopodiché aprire il file scaricato e seguire le istruzioni per installarlo mostrate a schermo.

### Uso
Ogni volta che il password manager viene aperto, il software richiede dall'utente la master password: una password che
l'utente deve inserire, e non salvare da nessuna parte, tanto meno riutilizzare, affinché egli possa salvare e leggere
i propri dati.
